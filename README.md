# 마음을 잇는 대화 — 게임 구현

중학교 2학년 국어 수업용 대화 선택 게임. 확정 대본(`../대본/`)을 그대로 돌아가게 만드는 저장소다.

작업 지침은 **`CLAUDE.md`**에 있다. 코드를 고치기 전에 먼저 읽는다.

## 실행

JSON을 `fetch`로 읽기 때문에 파일을 그냥 두 번 클릭하면 열리지 않는다. 로컬 서버가 필요하다.

```
cd game
node tools/로컬_서버.mjs
```

브라우저에서 `http://localhost:8000`을 연다.
기본 포트가 사용 중이면 `node tools/로컬_서버.mjs 8010`처럼 포트 번호를 덧붙일 수 있다.

## 지금 되는 것

- 첫 접속 시 학교 교실 배경의 제목 오프닝이 뜬다. 화면을 누르면 교과서의 공감적 대화·갈등 조정 대화 방법을 소개하고, `게임 시작`을 눌러 본편에 들어간다. 저장된 진행이 있으면 안내 뒤 해당 장면에서 이어 간다.
- 01 선곡부터 05 공연 당일을 거쳐 06 엔딩 3종과 한 화면 〈학습 내용 정리〉까지 이어서 돌아간다.
- 조건부 문구, 회복 지점 진입 우선순위, 무대 기억 단계 기록, 해결/미해결 판정, 영역 집계가 데이터로 동작한다.
- 02의 직접 해결·통합 정정·미해결·사실 미확인 경로, 03의 두 의상안·자동 정정·회복·미해결 경로, 04의 사용·보류·자동 정정·회복·미해결 경로, 05의 기억·관계·정정·엔딩 분기, 06의 카드 선정 우선순위를 자동 검사한다.
- 돌아보기 카드에는 실제로 고른 말과 그때의 해슬 반응이 다시 표시된다.
- 부적절한 선택지 20개에는 인물의 반응 뒤 `대화 신호`가 나타나, 그 표현이 왜 지금 상황에 적절하지 않았는지 한 문장으로 알려 준다. 선택 전에는 표지를 보여 주지 않는다.
- 공감·갈등 조정 영역 중 덜 사용한 쪽이 있으면, 개인별 해설 안에서 다음에 연습할 대화 방법을 안내한다. 두 영역이 모두 부족하면 공감 영역을 먼저 안내한다.
- 상단에서 지금까지 본 대화를 확인하고, 글자를 크게 바꿀 수 있다. 진행 지점·대화 기록·글자 설정은 개인정보 없이 현재 브라우저에 자동 저장된다.
- 높이가 낮은 노트북에서는 질문과 선택지를 좌우로, 좁은 화면에서는 세로로 배치한다.
- 시간·장소가 바뀌면 장면 전환 화면을 먼저 보여 준다.
- 일반 대화에서는 현재 발화만 화면 아래 1/5 이내의 대화창에 표시하고, 앞선 내용은 `대화 기록`에서 확인한다.
- 해슬·서연·민서·지호·도윤이 말하면 해당 전신 캐릭터가 나타난다. 해슬은 대사 맥락에 따라 6종, 서연은 밝은 제안과 아쉬움 2종, 민서·지호·도윤은 각자의 대사 성격에 맞는 1종으로 바뀐다. 주인공은 이미지로 표시하지 않는다.
- 엔딩 진입 때 공연 성공·공연 포기·무대 실패를 각각 전면 컷신으로 보여 준다. 공연 성공에는 무대 위에서 함께 연주하는 기존 그림, 공연 포기에는 다른 팀의 무대를 바라보는 그림, 무대 실패에는 연주가 어긋나 멈칫한 그림을 쓴다. 의상 결정 기록에 따라 남색·검정 또는 흰 상의·청바지 그림으로 바뀐다. 공연 성공 컷신에는 느린 카메라 움직임과 조명 효과가 있고, 움직임 줄이기 설정에서는 효과를 끈다.
- 엔딩 대사가 끝나면 별도의 `이야기 끝` 화면을 거쳐 스크롤형 〈학습 내용 정리〉가 나온다. 실제 선택·해슬의 반응·조건부 해설, 공감 5가지·갈등 조정 7가지, 학습지 성찰 질문을 한 화면에서 확인하며, 큰 저장 버튼으로 이 내용을 PNG 이미지로 내려받을 수 있다. 기존 성찰 단계에서 저장한 진행도 새 정리 화면으로 자동 연결한다.
- 배경은 웹용으로 줄인 JPEG 6장(합쳐 약 1.18MB). 원본 PNG는 `../output/backgrounds_v01/`에 있다.
- 캐릭터는 웹용 투명 WebP 11장(높이 900px, 합쳐 약 512KB). 원본 PNG는 `../output/character_design/`의 각 전신 스프라이트 폴더에 있다.
- 엔딩 컷신은 웹용 WebP 6장(각 300KB 이하). 원본 PNG와 제작 기록은 `../output/ending_art/`에 있다.

## 배포

정적 사이트다. 빌드가 없다. `game/` 폴더를 그대로 정적 호스팅에 올리면 학생이 주소로 접속한다.

올리기 전에 확인할 것.

- 이미지 총량이 늘지 않았는지. 장당 300KB, 현재 전체 약 2.64MB(배경·캐릭터·엔딩 컷신 포함)를 기준으로 확인한다.
- 외부 CDN·폰트·분석 스크립트를 넣지 않았는지. 학교망에서 막히면 게임이 멈춘다.
- 학생 개인 정보를 저장하거나 보내지 않는지.
